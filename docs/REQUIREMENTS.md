# ニュース動画自動生成システム - 要件定義書

## 1. プロジェクト概要

### 1.1 目的
世界中の最新ニュースを自動収集し、YouTube ShortsやTikTok向けのショート動画を生成するシステムを構築する。

### 1.2 ターゲットプラットフォーム
- YouTube Shorts
- TikTok
- Instagram Reels

### 1.3 出力言語
- 日本語版
- 英語版
（同一ネタから両言語の動画を生成）

### 1.4 自動化レベル
**セミオート方式**を採用：
- ニュース収集・要約：自動
- ネタ選定：**人間が確認・選択**
- 深掘り調査・台本生成：自動
- 台本確認：**人間が確認・承認**
- アセット生成（音声・画像）：自動
- 動画合成：自動
- 最終確認：**人間が確認・承認**
- 投稿：手動 or 承認後自動

## 2. 機能要件

### 2.1 Phase 1: ニュース収集機能

#### FR-1.1 RSSフィード取得
- 複数のRSSフィードから記事を取得
- 対象ソース例：
  - TechCrunch
  - The Verge
  - Wired
  - Reuters
  - 日経新聞（テック系）
  - その他カスタム追加可能

#### FR-1.2 NewsAPI連携
- NewsAPI.orgからトピック別ニュースを取得
- カテゴリ：technology, science, business など

#### FR-1.3 重複排除
- 同一ニュースの重複を検出・除外
- タイトル類似度によるフィルタリング

#### FR-1.4 AI要約・スコアリング
- 各ニュースを要約（100文字程度）
- バイラル可能性スコア（1-10）を付与
- スコアリング基準：
  - 話題性
  - 視覚的インパクト
  - ターゲット層との関連性

#### FR-1.5 ネタ候補リスト出力
- スコア順にソートされたリストを出力
- 出力先：Google Sheets / Notion / JSON

---

### 2.2 Phase 2: ネタ選定・深掘り機能

#### FR-2.1 ネタ選定UI
- ネタ候補リストを表示
- チェックボックスで選択
- 選択したネタを次フェーズへ

#### FR-2.2 深掘り調査
- 選定されたネタについてWeb検索
- 関連情報・データ・引用を収集
- 使用API：Perplexity API / Tavily / Web Search

#### FR-2.3 台本生成
- 深掘り情報をもとに動画台本を生成
- 台本構成：
  ```
  1. Hook（0-5秒）：視聴者を引き付ける導入
  2. Main（5-50秒）：本題（3ポイント程度）
  3. Conclusion（50-60秒）：まとめ + CTA
  ```

#### FR-2.4 画像プロンプト生成
- 台本の各シーンに対応する画像プロンプトを生成
- 4-6枚の画像プロンプト
- 英語で出力（Flux用）

#### FR-2.5 台本確認UI
- 生成された台本を表示
- 編集可能
- 承認ボタンで次フェーズへ

---

### 2.3 Phase 3: アセット生成機能

#### FR-3.1 音声生成（TTS）
- 台本テキストから音声を生成
- 使用API：ElevenLabs
- 日本語・英語それぞれ生成
- 出力形式：MP3

#### FR-3.2 画像生成
- 画像プロンプトからAI画像を生成
- 使用API：fal.ai (Flux)
- アスペクト比：9:16（縦型）
- 解像度：1080x1920
- 出力形式：PNG

#### FR-3.3 B-roll映像生成（オプション）
- 必要に応じてAI映像を生成
- 使用API：Google Veo / Runway
- 5-10秒のクリップ

#### FR-3.4 ストック素材取得（オプション）
- Pexels等から関連映像を取得
- キーワード検索
- ライセンス確認

---

### 2.4 Phase 4: 動画合成機能

#### FR-4.1 動画テンプレート
- Creatomateでショート動画テンプレートを作成
- テンプレート要素：
  - 背景画像/映像レイヤー
  - 音声レイヤー
  - テキストオーバーレイ（タイトル）
  - 字幕レイヤー
  - トランジション効果

#### FR-4.2 自動字幕生成
- 音声から字幕を自動生成
- 使用API：ElevenLabs Scribe / Whisper
- ワードハイライト形式

#### FR-4.3 動画レンダリング
- Creatomate APIで動画を生成
- 出力仕様：
  - 解像度：1080x1920
  - フレームレート：30fps
  - 形式：MP4
  - 長さ：30-60秒

#### FR-4.4 FFmpegフォールバック
- Creatomate利用不可時のローカル生成
- ffmpegコマンドで合成

---

### 2.5 Phase 5: 確認・投稿機能

#### FR-5.1 プレビュー機能
- 生成された動画をプレビュー表示
- 日本語版・英語版の切り替え

#### FR-5.2 メタデータ生成
- タイトル
- 説明文
- ハッシュタグ
- サムネイル候補

#### FR-5.3 投稿スケジュール（オプション）
- 投稿日時の指定
- プラットフォーム別の最適時間提案

#### FR-5.4 マルチプラットフォーム投稿（オプション）
- YouTube / TikTok / Instagram へ投稿
- 使用サービス：Blotato / Buffer / 各API

## 3. 非機能要件

### 3.1 パフォーマンス
- ニュース収集：5分以内
- 台本生成：30秒以内
- 音声生成：1分以内
- 画像生成：4枚で2分以内
- 動画合成：3分以内
- **1本の動画生成：合計10分以内**

### 3.2 信頼性
- API障害時のリトライ処理
- 部分的失敗時の再開機能
- 生成結果のローカル保存

### 3.3 拡張性
- 新規RSSソースの追加が容易
- 新規言語の追加が可能
- テンプレートの追加・変更が可能

### 3.4 運用性
- CLIとWebUI両対応
- ログ出力（処理状況の可視化）
- エラー通知（Discord/Slack）

## 5. ユーザーストーリー

### US-1: 毎日のニュース収集
```
毎朝、システムが自動的に世界中のテックニュースを収集し、
バイラル可能性でスコアリングされたリストを見たい。
そこから今日動画にするネタを3つ選びたい。
```

### US-2: 台本の確認と編集
```
AIが生成した台本を確認し、
必要があれば表現を修正してから
動画生成に進みたい。
```

### US-3: 日英両方の動画生成
```
1つのネタから日本語版と英語版の
両方の動画を生成したい。
画像は共通で使い回したい。
```

### US-4: 品質チェック
```
生成された動画をプレビューで確認し、
問題なければ投稿用にエクスポートしたい。
```

## 6. 制約事項

### 6.1 API制限
- ElevenLabs: 無料枠は10,000文字/月
- fal.ai: 従量課金（$0.03/メガピクセル程度）
- Creatomate: 月2,000クレジット（$54プラン）

### 6.2 著作権
- ニュース内容の引用は適切に行う
- 画像は全てAI生成を使用
- 音楽は著作権フリー素材のみ

### 6.3 プラットフォームポリシー
- AI生成コンテンツの開示が必要な場合あり
- 各プラットフォームの利用規約に準拠
